APPENDIX / THE CREATIVE ANALYST

Why this
platform?

Website platform justification · Review draft

This e-Portfolio is implemented as a custom, static multi-page website and hosted using Sites. The platform supports a shareable hosted experience, while the custom frontend gives flexibility over typography, layout, navigation and interaction. This suits a portfolio that needs to communicate both creative work and analytical thinking.

The website is organised into Home, About, Resume, Projects, Skills and Reflections. Dedicated case-study pages make each project easier to review using Situation, Task, Action, Result and Reflection. A separate reflections area supports deeper discussion of learning through Gibbs’ Reflective Cycle. This structure helps a lecturer inspect academic requirements and gives a recruiter a shorter path to work samples and career information.

The implementation uses semantic HTML, responsive CSS and lightweight JavaScript. The portfolio does not need server-side processing or a database, so a static approach reduces dependency and maintenance requirements. Content is held in a central build file and project data is also exported as JSON, making future edits more manageable.

Accessibility considerations include keyboard navigation, a mobile menu, visible focus states, readable text, reduced-motion support and meaningful page titles. Project category filters help visitors find relevant work. Missing photographs, contact details and original evidence are labelled clearly so the website does not imply that illustrative covers are authentic project artifacts.

Sites is selected here as the hosting platform rather than Wix or Google Sites. Its advantages for this portfolio are design control and a direct development-to-deployment workflow. Its trade-off is that larger content changes may need source editing rather than a visual drag-and-drop editor. Before assessment, the original resume, project evidence and contact details should be added, and the reflection drafts should be checked against personal experience.

The site begins with private access. Sharing with a lecturer or recruiter will require the appropriate access setting. This allows the portfolio to be reviewed before wider distribution.
