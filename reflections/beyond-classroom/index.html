Beyond the Classroom: My Experience in Fun Run 2026

Gibbs’ Reflective Cycle · Draft for personal review

Review draft: confirm personal details and add a real incident before submission.

01 / GIBBS’ CYCLE

Description

As a member of the Multimedia Committee for Fun Run 2026 — Encore of Tomorrow, I contributed to design work and event-day support. The work included merchandise such as T-shirts, lanyards, medals and string bags, as well as Facebook visuals, Instagram posters and a route map. During the event activities, I also supported photography, videography, VIP and participant coverage, route guidance and coordination across teams. This experience brought together visual communication and practical responsibility. It showed how creative materials become part of an event that people actually attend and experience.

03 / GIBBS’ CYCLE

Evaluation

One valuable aspect of the role was the variety of work. Merchandise, social media visuals and event photography each served a different purpose, so I had opportunities to think beyond a single design format. Working with other teams also gave me a better understanding of how an event depends on coordinated contributions. At the same time, a finished visual is only one part of successful communication. Timing, file handover and practical use matter too. My final evaluation should include a specific example of something that worked well and something I would improve, supported by actual experience.

04 / GIBBS’ CYCLE

Analysis

This experience helped me connect creativity with organisation. A design needs to communicate clearly, but it also needs to be ready for the people who will use it. Event coverage similarly involves choices about which moments to record and how to support the wider team. These responsibilities connect with marketing because consistent visuals, audience understanding and clear communication influence how an event is presented. I also see teamwork as a practical skill: confirming requirements, sharing updates and understanding another person’s task can reduce confusion. The lesson is that effective creative work includes the process around the deliverable.

05 / GIBBS’ CYCLE

Conclusion

The role developed my understanding of multimedia work as a combination of design, communication and service to the event team. It gave me opportunities to use visual skills while contributing to practical activities. I want to carry this perspective into marketing work, where creative execution has to support a purpose and fit a wider plan. I also recognise that I should keep improving my ability to prioritise, communicate changes and prepare for situations where several tasks need attention. These are useful lessons even when the next project is very different.

06 / GIBBS’ CYCLE

Action Plan

For a future event, I would prepare a shared checklist covering required visuals, review dates, final formats and the person responsible for each handover. For photography and video, I would agree on a shot list before the event and clarify priority moments with the team. I would also plan a simple method for organising files afterwards so that useful materials can be found easily. Before submitting this reflection, I will add an actual event-day example and explain my response, then review whether the action plan directly addresses what that example taught me.
